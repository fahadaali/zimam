# Button

زر الإجراء في زمام، بثلاثة أنواع: أساسي وثانوي وهادئ.

- **أساسي (`primary`):** إجراء واحد فقط في الشاشة، بخلفية `brand` ونص `on-brand`، مثل «إضافة مهمة» أو «حفظ».
- **ثانوي (`secondary`):** إجراء بديل بجانب الأساسي، بخلفية `surface-raised` وحدّ `line-strong`.
- **هادئ (`quiet`):** روابط داخل القوائم مثل «عرض الكل»، نصاً بلون `brand` بلا خلفية.
- النص فعل قصير بصيغة الأمر أو المصدر: «إضافة مهمة» لا «اضغط هنا».
- ارتفاع اللمس 44px على الأقل في كل المنصات.
- **يوفّر المستهلك:** `children` (النص)، و`onClick`، و`disabled` عند الحاجة.
- لا تضع زرّين أساسيين متجاورين، ولا أيقونة بلا نص إلا في شريط الأدوات مع `aria-label`.
