# DateChip

شريحة التاريخ، تعرض الهجري والميلادي معاً مفصولين بفاصلة عربية «،».

- التقويم الأساسي للمستخدم يأتي أولاً؛ الافتراضي في السعودية الهجري.
- الأرقام هندية عربية (١٢٣) في الواجهة العربية، وتتبع إعداد النظام.
- للتواريخ القريبة استعمل كلمة واحدة: «اليوم»، «غداً»، «الخميس».
- المتأخرة: `tone="overdue"` بلون `priority-high`، مع كلمة «متأخرة» لقارئ الشاشة.
- **يوفّر المستهلك:** `hijri` و/أو `gregorian` منسّقين مسبقاً، و`tone`.
