# KanbanColumn

عمود لوحة الكانبان: العنوان والعدّاد ثم بطاقات المهام، وزر إضافة في الأسفل.

- الأعمدة تُرتَّب من اليمين لليسار بترتيب سير العمل: «للتنفيذ» في أقصى اليمين.
- الخلفية `surface-sunken` والبطاقات `TaskRow` بخاصية `compact` فوقها.
- السحب بين الأعمدة يرفع البطاقة بـ `shadow-lift` ويُظهر موضع الإفلات بفراغ بارتفاع البطاقة.
- **يوفّر المستهلك:** `title`، و`children`، و`onAdd`، و`count` إن اختلف عن عدد البطاقات المعروضة.
