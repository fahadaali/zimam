# AISuggestion

بطاقة اقتراح المساعد الذكي: ما سيفعله المساعد، مع زرّي الاعتماد والتجاهل. لا يُطبَّق أي تغيير قبل الاعتماد.

- الخلفية `brand-soft`، والعنوان «اقتراح المساعد» بلون `brand-ink`.
- النص يصف النتيجة بصيغة الماضي كأنها تمت: «قسّمت…»، «نقلت…»، في جملة أو جملتين.
- لا أيقونات نجوم أو تدرجات لونية للدلالة على الذكاء الاصطناعي؛ الهوية هادئة.
- **يوفّر المستهلك:** النص في `children`، و`onAccept` و`onDismiss`.
