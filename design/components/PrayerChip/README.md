# PrayerChip

شريحة التذكير المرتبط بوقت الصلاة، وهي الميزة التي تميّز زمام، ولذلك لها لونها الخاص `sand`.

- الخلفية `sand-soft` والنص والأيقونة `sand`؛ لا يُستعمل هذا اللون لأي شيء آخر.
- الصياغة: «بعد/قبل + اسم الصلاة»، ثم المدة إن وُجدت: «بعد العصر بـ٢٠ د». لا تستعمل النقطة الوسطى «·» بجانب الأرقام.
- في سطر المهمة تعرض الشريحة **الساعة المحسوبة** ليوم المهمة مع أيقونة الصلاة: «٢:٥٠ م». تُحسب ليوم المهمة نفسه، فمهمة بعد شهر تأخذ عصر ذلك اليوم، والمهمة بلا تاريخ تأخذ وقت اليوم. وقارئ الشاشة يقرأ بعدها العبارة: «٢:٥٠ م، قبل العصر بـ١٠ د».
- العبارة «قبل العصر بـ١٠ د» تظهر في تفاصيل المهمة بجانب الساعة، وتعديل الساعة يدوياً هناك يفصل المهمة عن الصلاة فتصير ساعة عادية.
- بلا موقع لا تُحسب الساعة، فتعرض الشريحة العبارة وحدها.
- **يوفّر المستهلك:** النص في `children` (الساعة أو العبارة)، والعبارة لقارئ الشاشة إن كان النص ساعة.
