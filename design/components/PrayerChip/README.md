# PrayerChip

شريحة التذكير المرتبط بوقت الصلاة، وهي الميزة التي تميّز زمام، ولذلك لها لونها الخاص `sand`.

- الخلفية `sand-soft` والنص والأيقونة `sand`؛ لا يُستعمل هذا اللون لأي شيء آخر.
- الصياغة: «بعد/قبل + اسم الصلاة»، ثم المدة إن وُجدت: «بعد العصر بـ٢٠ د». لا تستعمل النقطة الوسطى «·» بجانب الأرقام.
- لا تعرض الوقت بالساعة داخل الشريحة؛ الوقت يتغير يومياً ويظهر في تفاصيل المهمة.
- **يوفّر المستهلك:** النص في `children`.
