# ProjectCard

بطاقة المشروع في الشاشة الرئيسية وشبكة المشاريع على الآيباد والماك: الاسم، وعدد المنجز من الكل، وشريط التقدم.

- الاسم بنمط `headline`، والعدّاد بنمط `caption` بلون `ink-muted` بصيغة «٧ من ١٢» بالأرقام الهندية العربية.
- شريط التقدم بلون `brand` فوق `surface-sunken`، بلا نسبة مئوية مكتوبة.
- النشط (المفتوح حالياً): خلفية `brand-soft`.
- **يوفّر المستهلك:** `name` و`done` و`total`، واختيارياً `due` و`active`.
- لا تضع أيقونات أو رموزاً تعبيرية للمشاريع؛ اللون الوحيد المسموح هو `brand`.
