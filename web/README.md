# موقع زمام

صفحة التعريف بزمام وواجهة إدارة المهام من المتصفح، على Cloudflare Workers.

- الرموز والخط من `../design/generated/tokens.css` وملفات `../design/fonts/web/`.
- الشعار من `../design/logos/`، وأيقونة المتصفح `../design/app-icons/favicon.svg`.
- المكوّنات المرجعية في `../design/components/` (`bundle.js` و`bundle.css`).
- النطاق المقترح: `zimam.app`.
