# وثيقة فكرة تطبيق زمام

> النسخة الحية من هذه الوثيقة: https://claude.ai/code/artifact/c78b643b-19bd-48d6-a053-94a66f75241e — هذا الملف نسخة منها في المستودع (13 أكتوبر 2026).

## الرؤية والقيمة المميزة

مدير مهام عربي أولاً لأجهزة أبل الأربعة، يتميّز بثلاثة أمور لا تجتمع في تطبيق واحد اليوم: وصول مساعدات الذكاء الاصطناعي (كلود وChatGPT) إلى المهام قراءةً وتعديلاً، وتقويم هجري وميلادي كامل، وتذكيرات مرتبطة بأوقات الصلاة المحلية.

**المشكلة:** تطبيقات المهام الحالية (TickTick وMicrosoft To Do وتذكيرات أبل) قوية في الأساسيات، لكنها:

- لا تفتح بياناتها لمساعدات الذكاء الاصطناعي بشكل أصيل، فيبقى المستخدم ينسخ ويلصق بين التطبيق والمساعد.
- تتعامل مع العربية كترجمة لا كلغة أصلية، ولا تدعم الهجري ولا أوقات الصلاة.
- تجبر المستخدم على الاختيار بينها، بدل أن تجمع مهامه المتفرقة في مكان واحد.

**القيمة المقترحة:** مكان واحد للمهام الشخصية والمشتركة، يستورد من الأدوات الأخرى، ويضيف المهام بالصوت وسيري، ويتحدث معه كلود وChatGPT مباشرة.

**اسم التطبيق:** «زِمام» (Zimam)، بشعار «خذ زمام يومك»، وبهوية مستقلة لا ترتبط بناف. الشخصية البصرية هادئة ومركّزة، واللون الأساسي من عائلة الأزرق والنيلي.

## المستخدم المستهدف ومراحل الاستخدام

زمام إصدار تجاري واحد بكامل الخصائص من اليوم الأول. يُستعمل أولاً استعمالاً شخصياً للتجربة، ثم يُطرح للجمهور مباشرة دون مرحلة وسيطة؛ لذلك تُبنى الحسابات والمشاركة والاشتراكات قبل التجربة، وتُختبر كلها خلالها.

| المرحلة | المستخدم | ما يحدث |
| --- | --- | --- |
| ١. تجربة شخصية | فهد، مع حسابات تجريبية لاختبار المشاركة | الإصدار الأول بكامل خصائصه على الأجهزة الأربعة والموقع، والاشتراكات في وضع الاختبار |
| ٢. إطلاق تجاري | الجمهور عبر App Store والموقع | الإصدار نفسه دون تغيير في الخصائص، مع تفعيل الاشتراكات وحصص الذكاء الاصطناعي |

**الشريحة المستهدفة عند النشر:** المهنيون العرب في الخليج ممن يعتمدون على أجهزة أبل، ويديرون مهام شخصية ومهنية معاً، ويستخدمون مساعدات الذكاء الاصطناعي في عملهم.

## التكاملات والذكاء الاصطناعي وخادم MCP

التكاملات ثلاث طبقات: استيراد من التطبيقات الأخرى، ومساعد ذكاء اصطناعي داخل التطبيق، وخادم MCP يفتح التطبيق لكلود وChatGPT من الخارج.

### ١. الاستيراد ثم المزامنة

| المصدر | طريقة الوصول | الإصدار الأول | الإصدار الثاني |
| --- | --- | --- | --- |
| تذكيرات أبل وتقويم أبل | EventKit على الجهاز مباشرة | استيراد | مزامنة ثنائية |
| Google Calendar | Google Calendar API عبر OAuth | استيراد الأحداث وعرضها | مزامنة ثنائية |
| TickTick | TickTick Open API | استيراد المهام والقوائم | مزامنة ثنائية |
| Microsoft To Do | Microsoft Graph API | استيراد المهام والقوائم | مزامنة ثنائية |
| Notion | Notion API | استيراد قاعدة بيانات مهام | مزامنة ثنائية |
| Trello وAsana | واجهاتهما الرسمية | استيراد البطاقات والمهام | مزامنة ثنائية |

الاستيراد من كل المصادر يدخل الإصدار الأول دفعة واحدة، لتكون التجربة الشخصية كاملة. ويُبنى بطبقة «محوّل» موحّدة لكل مصدر، حتى تتحول لاحقاً إلى مزامنة دون إعادة بناء.

### ٢. المساعد الذكي داخل التطبيق

- **الإضافة باللغة الطبيعية:** «ذكرني أراجع العقد بعد المغرب يوم الخميس» تتحول إلى مهمة بتاريخ وتذكير مرتبط بالصلاة.
- **تقسيم المهام الكبيرة** إلى مهام فرعية قابلة للتنفيذ.
- **ملخص يومي** صباحي بمهام اليوم والمتأخرات.
- **المزوّد قابل للتبديل:** كلود أو DeepSeek أو غيرهما، عبر طبقة موحّدة على الخادم.
- **المفتاح محفوظ في الخادم لا في التطبيق:** يمر كل طلب عبر خادم كلاودفلير، فلا يُكشف المفتاح، ويُحسب استهلاك كل مستخدم للاشتراكات.

### ٣. خادم MCP على كلاودفلير

خوادم MCP البعيدة تُبنى على Cloudflare Workers، ومعها مكتبة جاهزة تتولى تسجيل الدخول عبر OAuth، فيتصل كلود أو ChatGPT بحساب المستخدم بإذنه.

| الأداة | ما تفعله |
| --- | --- |
| `list_tasks` | عرض المهام حسب اليوم أو المشروع أو الحالة |
| `search_tasks` | البحث في المهام والملاحظات |
| `create_task` | إضافة مهمة بتاريخها وتذكيراتها |
| `update_task` | تعديل مهمة أو نقلها أو تأجيلها |
| `complete_task` | إنجاز مهمة |
| `list_projects` | عرض المشاريع ومحتواها |
| `get_agenda` | جدول يوم أو أسبوع بالهجري والميلادي مع أوقات الصلاة |

**التوافق:** كلود يدعم الموصلات المخصصة في كل الخطط (المجانية تقتصر على موصل واحد). ChatGPT يتطلب تفعيل وضع المطوّر في الخطط المدفوعة، والمصادر تتباين حول الخطط الشخصية؛ يُتحقق منه وقت التنفيذ.

## المعمارية التقنية

تطبيق أصلي واحد بـ SwiftUI لأجهزة أبل الأربعة، يعمل محلياً دون اتصال، ويتزامن مع خادم موحّد على حساب كلاودفلير يخدم التطبيق والويب وكلود وChatGPT معاً.

```
 تطبيق أبل (SwiftUI)      واجهة الويب         المساعدات الخارجية (كلود · ChatGPT)
          │                   │                          │
          └───────┬───────────┘                          │
                  ▼                                      ▼
 ┌─────────────────────────── كلاودفلير ───────────────────────────┐
 │  الواجهة البرمجية (Workers)        خادم MCP (Workers + OAuth)     │
 │  بوابة الذكاء (AI Gateway)          المهام الخلفية (Queues · Cron)  │
 │          قاعدة البيانات D1 · Durable Objects للمزامنة اللحظية        │
 └──────────────────────────────────────────────────────────────────┘
          │                       │                       │
   مصادر الاستيراد       مزوّدو الذكاء الاصطناعي      إشعارات أبل (APNs)
```

كل طلب يمر عبر الخادم نفسه، فتبقى البيانات ومفاتيح الذكاء الاصطناعي في مكان واحد، ولا يُحفظ أي مفتاح داخل التطبيق.

**على الجهاز:**

- **SwiftUI** متعدد المنصات لكود مشترك بين الآيفون والآيباد والماك والساعة.
- **SwiftData** للتخزين المحلي والعمل دون اتصال، ثم المزامنة عند الاتصال.
- **App Intents** لسيري والاختصارات وApple Intelligence.
- **WidgetKit وActivityKit** للويدجت وLive Activities.
- **EventKit** لاستيراد تذكيرات أبل وتقويمها.
- **التقويم الهجري** عبر تقويم أم القرى المدمج في أنظمة أبل، و**أوقات الصلاة** بمكتبة حساب مفتوحة المصدر تعمل على الجهاز دون إنترنت.

**تسجيل الدخول:** Sign in with Apple، وهو نفسه ما يعتمد عليه خادم MCP عند ربط كلود أو ChatGPT بالحساب.

**على كلاودفلير (الحساب القائم):**

| الخدمة | الدور في زمام |
| --- | --- |
| Cloudflare Pages / Workers static assets | موقع الويب: صفحة التعريف بالتطبيق، وواجهة إدارة المهام من المتصفح |
| Workers | الواجهة البرمجية التي يتزامن معها التطبيق والموقع، والحسابات والاشتراكات |
| Workers + OAuth | خادم MCP الذي يتصل به كلود وChatGPT بإذن المستخدم |
| D1 وDurable Objects | قاعدة البيانات، والمزامنة اللحظية للمهام المشتركة |
| Queues وCron | الاستيراد من المصادر الأخرى، وجدولة إشعارات الصلاة من الخادم |
| AI Gateway | توجيه طلبات المساعد إلى كلود أو DeepSeek، وحصص الاستهلاك لكل مستخدم |

الموقع والواجهة البرمجية وخادم MCP على نطاق واحد، مثل `zimam.app` و`api.zimam.app` و`mcp.zimam.app`، بعد التحقق من توفّر النطاق.

## الهوية ونظام التصميم

زمام هوية مستقلة، شخصيتها هادئة ومركّزة، ومرجعها الكامل `design/README.md` (والنسخة الحية: https://claude.ai/artifact/WpuhtMwKBDwQbiEpdNCKiu).

- **الألوان:** نيلي واحد يُستعمل باقتصاد للإجراءات، ولون رملي مخصص لأوقات الصلاة وحدها، وأسطح محايدة متدرجة بدل الظلال.
- **الخط:** خط ثمانية في التطبيق والموقع والشعار: thmanyah sans للواجهة، وthmanyah serif display لعناوين التسويق. المدّ والأحرف المرسلة والكشيدة المائلة تُفعَّل في الشعار والعناوين الكبيرة فقط، ولا تُستعمل في عناوين المهام أو نص المستخدم، ورمز الريال يظهر تلقائياً في الأسعار.
- **الاتجاه:** عربي من الجذور؛ كل تخطيط يبدأ من اليمين، وأعمدة الكانبان تسير من اليمين لليسار.
- **الأرقام والتواريخ:** أرقام هندية عربية، والفاصل بين الهجري والميلادي الفاصلة العربية «،» لا النقطة الوسطى، لأن الصفر العربي نقطة.
- **المكوّنات الأساسية:** سطر المهمة، وشريحة التاريخ، وشريحة الصلاة، وبطاقة المشروع، وعمود الكانبان، وبطاقة اقتراح المساعد، والزر.
- **الشعار:** رمز «دائرة اليوم»: دائرة إنجاز مقسومة إلى خمسة أقواس هي الصلوات الخمس، ونقطة رملية هي الصلاة الحالية، وعلامة إنجاز في الوسط. ملفاته بالعربية واللاتينية، وأيقونات التطبيق والساعة والمتصفح والحسابات، في `design/logos/` و`design/app-icons/`.

## خارطة الإصدارات

الإصدار الأول واحد بكامل الخصائص: يُجرَّب شخصياً، ثم يُطلق تجارياً مباشرة بعد اجتياز بوابة التجربة. المزامنة الثنائية وحدها تُرجأ للإصدار الثاني.

| المرحلة | ما تشمله | البوابة للانتقال |
| --- | --- | --- |
| الإصدار الأول · تجربة شخصية | كل الخصائص: المهام والمشاريع والواجهات والمشاركة؛ آيفون وآيباد وماك وساعة أبل، وموقع ويب وخادم MCP على كلاودفلير؛ الهجري والصلاة، سيري، الاستيراد من كل المصادر، المساعد الذكي | تجربة شخصية مستقرة، وقبول المراجعة في App Store |
| الإطلاق التجاري · الجمهور عبر App Store والموقع | الإصدار نفسه دون تغيير في الخصائص؛ تفعيل الاشتراكات وحصص الذكاء الاصطناعي لكل مشترك؛ سياسة الخصوصية وشروط الاستخدام | استقرار الإطلاق وملاحظات المستخدمين |
| الإصدار الثاني · بعد الإطلاق | المزامنة الثنائية مع كل المصادر؛ باقة الفرق والفوترة لكل مقعد؛ خيار «أحضر مفتاحك» للذكاء الاصطناعي | — |

المدد الزمنية تُحدّد بعد حسم من يبني التطبيق (انظر القرارات المفتوحة).

## نموذج الربح والاشتراكات

المقترح نموذج «مجاني + اشتراك» عبر StoreKit 2، والذكاء الاصطناعي ضمن الاشتراك بمفتاحك أنت، بحصة شهرية لكل مشترك تضبط التكلفة.

| الباقة | ما تشمله |
| --- | --- |
| مجانية | المهام والمشاريع، الهجري والميلادي، تذكيرات الصلاة، الويدجت، سيري، استيراد من تذكيرات أبل |
| احترافية (شهري/سنوي) | المساعد الذكي بحصة شهرية، خادم MCP لكلود وChatGPT، الاستيراد من كل المصادر، ساعة أبل |
| فرق | المهام والمشاريع المشتركة، الإسناد والصلاحيات، فوترة لكل مقعد |

الأسعار تُحدد بعد قياس متوسط تكلفة الذكاء الاصطناعي لكل مستخدم في فترة التجربة الشخصية. خيار «أحضر مفتاحك» يمكن إضافته لاحقاً لمن يريد استخداماً بلا حدود.

## المخاطر والقيود والقرارات المفتوحة

أكبر قيد تقني هو حد الإشعارات المحلية في iOS (64 إشعاراً مجدولاً للتطبيق الواحد)، وأكبر مخاطرة هي المزامنة الثنائية؛ ولكل منهما معالجة مقترحة.

| الخطر أو القيد | الأثر | المعالجة المقترحة |
| --- | --- | --- |
| حد 64 إشعاراً مجدولاً في iOS | تذكيرات الصلاة اليومية والمتكررة تستهلك الحد بسرعة | جدولة نافذة متجددة لأقرب الأيام، مع إشعارات من الخادم (APNs) لما بعدها |
| تعارض البيانات في المزامنة الثنائية | مهام مكررة أو تعديلات ضائعة | تأجيلها للإصدار الثاني، وتصميم معرّفات خارجية وسجل تغييرات من الإصدار الأول |
| تغيّر واجهات الطرف الثالث | توقف استيراد مصدر ما | محوّل منفصل لكل مصدر، يُعطَّل وحده دون أثر على بقية التطبيق |
| مراجعة App Store | رفض بسبب الاشتراكات أو محتوى الذكاء الاصطناعي | الاشتراكات عبر StoreKit فقط، وسياسة خصوصية واضحة لمعالجة البيانات بالذكاء الاصطناعي |
| نظام حماية البيانات الشخصية السعودي | التزامات على جمع بيانات المستخدمين ونقلها خارج المملكة | مراجعة موقع تخزين البيانات وشروط المزوّدين قبل النشر العام |
| تكلفة الذكاء الاصطناعي | تجاوز الاستهلاك لقيمة الاشتراك | حصص شهرية وتتبع الاستهلاك لكل مستخدم عبر Cloudflare AI Gateway |
