# تطوير الواجهة البرمجية

Worker على كلاودفلير بـ Hono وD1. كل الأوامر من داخل `api/`.

```sh
npm install        # npm 11 أو أحدث؛ npm 10 يتعطّل مع vitest 5
npm test           # الاختبارات داخل بيئة Workers الحقيقية (Miniflare) مع D1 محلية
npm run typecheck
npm run dev        # خادم محلي على http://localhost:8787
npm run db:migrate:local
```

## الهيكل

| الملف | ما فيه |
| --- | --- |
| `migrations/` | مخطط قاعدة البيانات D1، ملف لكل تغيير ولا يُعدَّل ملف بعد نشره |
| `src/auth/` | التحقق من رمز Sign in with Apple، وجلسات الخادم (يُحفظ تجزيء الرمز فقط) |
| `src/data/schemas.ts` | شكل كل كيان وقيوده (zod) |
| `src/data/mutations.ts` | كل كتابة تمر من هنا: الصلاحيات، والأحدث يفوز، وسجل التغييرات |
| `src/data/pull.ts` | ما تغيّر للمستخدم منذ مؤشر معيّن |
| `src/data/membership.ts` | إضافة الأعضاء وإزالتهم وما يلزم مزامنتهم |
| `src/routes/` | المسارات |

## المزامنة

التطبيق يعمل دون اتصال، ويتزامن بطلبين:

- `POST /v1/sync` يرسل التعديلات المحلية `{ mutations: [{ op: "upsert", entity, data } | { op: "delete", entity, id, updatedAt }] }`، وتُطبَّق بالترتيب، ولكل واحدة نتيجتها: `applied` أو `stale` (عند الخادم نسخة أحدث) أو `gone` (محذوفة) أو `forbidden` أو `invalid`.
- `GET /v1/sync?cursor=N` يرجع آخر حالة لكل سجل تغيّر بعد المؤشر، أو `delete` إن حُذف أو لم يعد ظاهراً للمستخدم، ثم المؤشر الجديد. يحفظ التطبيق المؤشر ويكرر الطلب ما دام `hasMore` صحيحاً.

الكيانات: `project` و`section` (أعمدة الكانبان) و`task` و`reminder` و`comment`. المعرّفات UUID يولّدها التطبيق، و`updatedAt` بالملّي ثانية من وقت التعديل على الجهاز، والأحدث يفوز.

- مهمة بلا مشروع في صندوق صاحبها وحده. مهام المشروع يراها كل أعضائه، ويعدّلها المالك والمحرر.
- التذكيرات شخصية: كل عضو في مشروع مشترك يضع تذكيراته ولا يراها غيره.
- موعد المهمة تاريخ ميلادي محلي (`dueDate`)، والهجري يُحسب في التطبيق بتقويم أم القرى. أو تُربط بصلاة: `duePrayer` و`duePrayerOffset` بالدقائق.
- نقل مهمة بين المشاريع ينقل مهامها الفرعية، ويُبلَّغ أعضاء المشروع القديم بحذفها من عندهم.

## المشاركة

الأدوار: المالك والمحرر يعدّلان، والمشاهد يقرأ ويعلّق، والمالك وحده يحذف المشروع ويدعو ويغيّر الأدوار ويزيل الأعضاء.

- الدعوة رابط `https://zimam.app/join/<code>` يُستعمل مرة واحدة وينتهي بعد ٧ أيام. يُحفظ تجزيء الرمز فقط في جدول `invites`، فلا يظهر الرمز بعد إنشائه.
- من يقبل دعوة وهو عضو يبقى على الأعلى من دوره ودور الدعوة، ولا تُستهلك الدعوة إلا إذا رفعت دوره.
- المجلدات لا تُشارَك، لأن مشاركة المجلد لا تشارك المشاريع التي فيه.

العضو الجديد مؤشره تجاوز سجلات المشروع القديمة، والعضو المُزال لا تصله تغييرات المشروع بعد خروجه. لذلك يُضاف عند القبول وعند الإزالة سجل تغيير موجّه للمستخدم نفسه (`user_id`) لكل ما هو حي في المشروع: المشروع وأعمدته ومهامه وتعليقاتها. وطلب `GET /v1/sync` يتحقق من الظهور عند السحب، فتصل للعضو الجديد كاملة، وتصل للمُزال حذفاً. وعند الإزالة أيضاً تُلغى إسناداته في المشروع، وتُحذف تذكيراته على مهامه.

## الواجهة البرمجية للموقع وخادم MCP

| المسار | ما يفعله |
| --- | --- |
| `POST /v1/auth/apple` | `{ identityToken, nonce?, name?, device? }` يرجع `{ token, user }` |
| `POST /v1/auth/logout` | ينهي الجلسة |
| `GET`, `PATCH`, `DELETE /v1/me` | الحساب والإعدادات (`calendar`، `prayerMethod`، `weekStart`)، والحذف يمسح بيانات المستخدم |
| `GET`, `POST /v1/projects` | المشاريع مع عدد المهام والمنجز منها |
| `GET`, `PATCH`, `DELETE /v1/projects/:id` | المشروع وأعمدته |
| `GET /v1/tasks` | تصفية بـ `projectId` (أو `inbox`) و`status` (أو `open`) و`dueFrom` و`dueTo` و`q` و`assignee=me` |
| `POST /v1/tasks`، `GET`, `PATCH`, `DELETE /v1/tasks/:id` | المهمة |
| `POST /v1/tasks/:id/complete` | إنجاز مهمة |
| `GET /v1/projects/:id/members` | الأعضاء `{ members: [{ userId, name, role, addedAt }] }`، لكل عضو |
| `PATCH /v1/projects/:id/members/:userId` | `{ role: "editor" \| "viewer" }`، للمالك، ولا يتغيّر دور المالك |
| `DELETE /v1/projects/:id/members/:userId` | المالك يزيل عضواً، أو العضو يغادر. المالك لا يغادر (`owner_cannot_leave`) |
| `GET`, `POST /v1/projects/:id/invites` | للمالك: الدعوات السارية دون رموزها، وإنشاء دعوة `{ role }` ترجع `{ code, url, expiresAt }` |
| `GET /v1/invites/:code` | معاينة الدعوة `{ projectName, role, invitedBy, expiresAt }`، و410 إن انتهت أو استُعملت (`invite_expired`، `invite_used`) |
| `POST /v1/invites/:code/accept` | الانضمام إلى المشروع، يرجع `{ projectId, role }` |
| `GET`, `POST /v1/tasks/:id/comments` | تعليقات المهمة من الأقدم مع `authorName`، وإضافة تعليق `{ body }` |
| `DELETE /v1/comments/:id` | حذف تعليق، لكاتبه فقط |

كل المسارات بعد تسجيل الدخول تحتاج `Authorization: Bearer <token>`. الأخطاء بالشكل `{ error: { code, message } }`؛ الرمز ثابت بالإنجليزية، والتطبيق يعرض نصه العربي.

البحث `q` يتجاهل التشكيل والتطويل، ويوحّد الألف والتاء المربوطة والألف المقصورة، ويطابق الأرقام الهندية بالعربية.

## لم يُبنَ بعد

- إلغاء الدعوة قبل استعمالها: العمود `revoked_at` موجود ولا مسار له بعد.
- إلغاء رمز Apple عند حذف الحساب (يحتاج مفتاح Sign in with Apple في أسرار كلاودفلير).
- المساعد الذكي عبر AI Gateway، وإشعارات APNs، والاستيراد عبر Queues، والمزامنة اللحظية بـ Durable Objects.
